This page is my Week 9 homework for the Web Programming course at Gachon University. It lists the Git commands I used for the exercises E1 to E3 and what each one did.

E1: first repository and first commit

CommandWhat it does
git clone https://github.com/MSukhrob/webpro-w9.gitDownloads the empty GitHub repository. It already has origin set, so it replaces git init and git remote add.
git checkout -b mainCreates and switches to the main branch.
git statusShows that index.html is untracked.
git add index.htmlStages the file.
git commit -m "Initial commit: add index.html"Saves the first snapshot.
git log --onelineShows the commit history.

E2: branch and merge

CommandWhat it does
git checkout -b feature-styleCreates a feature branch and switches to it.
git add style.css index.htmlStages the new stylesheet and the link to it in the HTML.
git commit -m "Add basic stylesheet"Commits the change on the feature branch.
git checkout mainGoes back to main, where style.css does not exist yet.
git merge --no-ff feature-styleMerges the branch into main and keeps a merge commit, so the branch stays visible in the history.
git log --oneline --graphShows the branch and the merge as a graph.

E3: push to GitHub

CommandWhat it does
git push -u origin mainUploads all commits to GitHub and links local main with origin/main.
git pushUploads later commits, such as this page update.

What I did

  1. Created the public repository webpro-w9 on GitHub without a README.
  2. Added index.html with my name and the date, and made the first commit.
  3. Created the branch feature-style, added style.css, committed, and merged it into main.
  4. Pushed everything to GitHub.
  5. Enabled GitHub Pages (Settings, Pages, Deploy from branch, main, /(root)).
